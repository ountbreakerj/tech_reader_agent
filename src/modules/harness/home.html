Harness 工程

从零写一个可用的 Agent Harness

模型只负责提出下一步，读文件、跑命令、管权限、记历史、失败重试，全都由模型外面的那层程序来做，这层程序就是 Harness。这里按机制拆成 26 章，每一章都对照 DSH、OpenHarness、learn-claude-code 等真实仓库的源码，给出可以直接运行的 Python 实现。

每章包含：一段主线故事、先看全貌的一节、各仓库的机制对照、可运行的 Python 代码（labs/ 目录，默认用 FakeLLM，不需要 API key）、坑与失败案例、多仓库取舍对比表。00–12 章的源码引用带 file:line，固定在具体 commit；13 章起侧重机制与取舍，用包名与函数名指代源码。凡是不来自源码的数字都标注“教学示意”。

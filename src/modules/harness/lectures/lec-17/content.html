首页/ Harness 工程/ 第 17 讲

第 17 讲 · 延伸阅读与资源

这门课覆盖了 harness 工程的核心概念。这一讲汇总了继续深入的方向：官方文档、关键实践者、值得追踪的研究，以及本课程内容的来源脉络。

官方文档

  • Claude Code 文档：claude.ai/code — hooks、skills、memory、MCP、worktrees 的完整参考。第 15 讲所有机制的权威来源。
  • Anthropic 工程博客：anthropic.com/engineering — 系统性 harness 实验（DAW 案例）、agent 可靠性研究、多 agent 架构设计的第一手资料。
  • OpenAI Codex 文档：platform.openai.com/docs/codex — AGENTS.md 规范、沙箱机制、并发任务设计的参考。
  • LangGraph 文档：langchain-ai.github.io/langgraph — 第 14 讲图工程原语（node/edge/state/routing）的 Python 实现参考。

关键实践者

以下实践者的公开写作和演讲是本课程内容的重要来源：

  • Boris Cherny（Meta）— 大规模 agent 工程实践，Loop 工程的早期实践者之一。
  • Peter Steinberger（PSPDFKit / Superapp）— "Graph 工程"概念的提出者之一，把 agent 组织成有向图的实践先驱。
  • Addy Osmani（Google Chrome）— AI 辅助工程的规模化实践，《AI-Assisted Engineering》作者。
  • Rohit（@rohit4verse）— 四层框架（Prompt → Context → Loop → Graph）的提出者。
  • Simon Willison（Datasette）— Agent 工程实践的长期观察者，大量一手实验记录。

研究论文

  • Guo et al. (2017) "On Calibration of Modern Neural Networks"，ICML — 神经网络系统性过度自信的经典证明，第 09 讲的理论基础。
  • Anthropic "Building Effective Agents" (2024) — 多 agent 架构、生成者-评估者分离、harness 设计的系统性总结。官方推荐的 agent 工程起点。
  • Google "Software Engineering at Google" — Testing chapters — 测试金字塔、测试分层的原始来源，第 09–10 讲的背景参考。
  • OpenAI "Practices for Governing Agentic AI Systems" (2025) — agent 架构约束、早期前置条件设计的实践总结，第 16 讲的部分来源。

工具与框架

  • LangGraph — Python 生态里最成熟的 graph 工程框架。节点/边/状态/路由四原语的参考实现。
  • Playwright MCP — 让 agent 像用户一样操作浏览器的 MCP 服务。Evaluator agent 的标准工具。
  • GitHub Actions — Automation 原语的通用实现。Claude Code 的 GitHub Actions 集成让 loop 触发条件可以是 PR 事件、定时任务等。
  • pytest / vitest — agent 场景下的测试框架首选。结构化输出，错误消息面向机器可读，易于集成到 harness 验证步骤。

课程脉络与概念图

这门课的 17 讲覆盖了 harness 工程的五个子系统：

子系统相关讲次核心问题
指令（Instructions）01–04Agent 怎么知道该做什么
状态（State）05–06跨会话的上下文怎么持久化
工具（Tools）07–08任务边界和完成条件怎么定义
验证（Verification）09–12怎么知道 agent 真的做完了
反馈（Feedback）13–16怎么让 agent 在循环里持续进步

建议的深入路径：把第 01–12 讲的核心原则在一个实际项目里逐一实施，大约 3–4 周后回来看第 13–16 讲，会对 Loop 和 Graph 工程的必要性有更直接的感受。理论容易懂，难的是在真实项目压力下坚持这些原则。

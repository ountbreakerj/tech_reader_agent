什么是NLP

自然语言处理（Natural Language Processing, NLP）是人工智能的核心分支，致力于让计算机理解、生成和处理人类语言。

NLP发展历程

NLP经历了四个主要发展阶段：

1
规则方法时代（1950s-1990s）
基于语法规则和专家知识，如正则表达式、模板匹配
2
统计方法时代（1990s-2010s）
基于概率统计，如朴素贝叶斯、HMM、最大熵模型
3
深度学习时代（2013-2018）
Word2Vec、RNN、LSTM、注意力机制
4
大模型时代（2018-至今）
BERT、GPT、LLaMA、Qwen等预训练大模型

NLP典型应用

任务描述代表产品关键技术
机器翻译自动翻译不同语言Google翻译、DeepLSeq2Seq、Transformer
情感分析判断文本情感倾向舆情监控系统BERT分类、Prompt

中文分词

中文分词是中文NLP的第一步。与英文不同，中文没有天然的空格分隔符，需要专门的分词算法。

jieba 分词三种模式

模式函数特点适用场景
精确模式jieba.lcut()最精确的切分，无冗余文本分析（推荐）
全模式jieba.lcut(cut_all=True)所有可能的词语都切出来搜索引擎召回
搜索引擎模式jieba.lcut_for_search()在精确模式基础上再切分长词搜索引擎索引

代码示例

Python 
import jieba

# 精确模式（默认，最常用）
text = "自然语言处理是人工智能的重要方向"
words = jieba.lcut(text)
print("精确模式：", words)

# 全模式（扫描所有可能的词语）
words_all = jieba.lcut(text, cut_all=True)
print("全模式：", words_all)

# 搜索引擎模式
words_search = jieba.lcut_for_search(text)
print("搜索引擎模式：", words_search)

# 添加自定义词典
jieba.add_word("大语言模型", freq=10000, tag="n")
jieba.add_word("RAG", freq=8000, tag="n")

Subword分词：现代NLP的主流方案

传统分词基于词典，无法处理未登录词（OOV）。现代NLP使用子词分词（Subword Tokenization）：

方法原理代表模型特点
BPE基于频率合并字节对GPT系列、LLaMA无需预分词，处理任意文本
WordPiece基于似然合并子词BERT类似BPE，使用##标记续接
SentencePiece语言无关的分词器T5、Qwen直接处理原始文本，不需预分词

Subword分词代码示例

Python 
from tokenizers import Tokenizer, models, trainers, pre_tokenizers

# 训练一个 BPE tokenizer
tokenizer = Tokenizer(models.BPE())
tokenizer.pre_tokenizer = pre_tokenizers.ByteLevel(add_prefix_space=False)
trainer = trainers.BpeTrainer(vocab_size=30000, min_frequency=2)
tokenizer.train(["corpus.txt"], trainer)

# 使用 tokenizer
output = tokenizer.encode("自然语言处理是人工智能的重要方向")
print("Tokens:", output.tokens)
print("Token IDs:", output.ids)

关键认知：现代LLM不使用jieba分词，而是使用BPE/SentencePiece等子词分词器。jieba仍适用于传统NLP任务（如关键词提取、简单分类）。

命名实体识别与词性标注

命名实体识别（NER）：从文本中识别出具有特定意义的实体。

词性标注（POS）：为每个词语标注其语法类别。

jieba 词性标注对照表

标签含义示例
n名词自然语言、模型
v动词处理、训练
a形容词重要的、强大的
nr人名张三、李四
ns地名北京、硅谷
nt机构名谷歌、百度

代码示例

Python 
import jieba.posseg as pseg

text = "2024年谷歌发布了Gemini大模型"
words = pseg.lcut(text)

# 提取命名实体
entities = {"nr": [], "ns": [], "nt": []}
for word, flag in words:
    if flag in entities:
        entities[flag].append(word)

print(f"人名: {entities['nr']}")
print(f"机构: {entities['nt']}")

# 词性标注结果
for word, flag in words:
    if len(word.strip()) > 0:
        print(f"  {word:10s} -> {flag}")

jieba的NER精度有限（约85%），生产环境建议使用 spaCy、HanLP 或基于BERT的NER模型。

文本数据增强

数据增强通过对原始文本进行变换来扩充训练数据集。

常用增强方法

方法原理难度效果
同义词替换将词语替换为同义词低中
随机删除以概率p删除词语低中
回译法翻译成外语再翻回来中高
LLM增强用大模型生成新样本高很高

代码示例

Python 
import random
import jieba

def synonym_replace(text, n=1):
    """同义词替换"""
    synonyms = {
        "模型": ["架构", "系统"],
        "训练": ["学习", "优化"],
    }
    words = list(jieba.cut(text))
    for _ in range(n):
        for i, w in enumerate(words):
            if w in synonyms:
                words[i] = random.choice(synonyms[w])
                break
    return "".join(words)

def random_delete(text, p=0.1):
    """随机删除"""
    words = list(jieba.cut(text))
    return "".join(w for w in words if random.random() > p)

text = "自然语言处理是人工智能的重要方向"
print("原始:", text)
print("同义替换:", synonym_replace(text))
print("随机删除:", random_delete(text))

数据增强比例建议控制在原始数据的1-3倍，过多增强会引入噪声。

实践：中文文本预处理流水线

将分词、停用词过滤、词性标注、词频分析串联起来，构建完整的中文文本预处理流水线。

完整流水线代码

Python 
import jieba.posseg as pseg
from collections import Counter

texts = [
    "自然语言处理是人工智能的重要方向",
    "BERT和GPT推动了NLP的快速发展",
    "大语言模型通过预训练获得了强大的能力",
    "文本数据增强可以缓解数据不足的问题",
]

stopwords = set(["的", "了", "在", "是", "我", "和", "就", "不"])
all_words = []
for text in texts:
    for word, pos in pseg.lcut(text):
        if len(word.strip()) > 0 and word not in stopwords:
            if pos.startswith(("n", "v", "a")):
                all_words.append(word)

counter = Counter(all_words)
print("词频排名 Top 10：")
for rank, (word, count) in enumerate(counter.most_common(10), 1):
    bar = "█" * count
    print(f"  {rank}. {word:8s} {count:3d} {bar}")

生产环境建议：1) 使用完整停用词表；2) 根据任务选择词性策略；3) 使用并行分词加速大规模处理。

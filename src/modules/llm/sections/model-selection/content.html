🎯 模型选型指南

根据需求和硬件选择最合适的模型

选型原则

类比：选模型就像选车——日常代步选经济型（小模型），长途旅行选SUV（中等模型），赛车比赛选超跑（大模型）。没有最好的车，只有最适合你需求的车。

决策流程

Python
# 模型选型决策指南

# 场景1：简单分类任务 → 用BERT系列
if task == "classification" and data_size < 100000:
    model = "bert-base-chinese"  # 或 roberta-base

# 场景2：文本生成 → 用Qwen/Llama系列
elif task == "generation":
    if gpu_memory >= 24:  # GB
        model = "Qwen3-14B"  # 或 Llama 3.1-8B
    elif gpu_memory >= 16:
        model = "Qwen3-8B"   # 或 Llama 3.1-8B (QLoRA)
    else:
        model = "Qwen3-4B"   # 或 Phi-4-mini

# 场景3：中文对话 → 用Qwen系列
elif task == "chat" and lang == "zh":
    model = "Qwen3-8B"

模型规模分类

规模参数量代表模型显存需求适用场景
小模型<1BQwen3-0.6B, Phi-4-mini2-4GB边缘设备、简单任务
中等模型1B-10BLlama 3.1-8B, Qwen3-8B8-16GB大多数应用（推荐）
大模型10B-70BQwen3-14B, Phi-4 (14B), Qwen3-32B24-80GB复杂推理、高质量生成
MoE模型总参数大/激活少Llama 4 Scout (109B/17B), Mixtral 8x7B (47B/13B)与激活参数相当大容量+低推理成本
超大模型参数量未公开（云端 API）GPT-5.5, Claude Opus 5, Fable 5云端最复杂的任务
推荐起点：从7B参数模型开始，这是性能和成本的最佳平衡点。在你的 RTX 4090 Laptop（16GB显存）上，可以QLoRA微调7-13B模型。新增的 DeepSeek-R1-distill 系列（蒸馏推理模型）也是高性价比选择。

RTX 4090 Laptop (16GB) 配置建议：
  • 注意：RTX 4090 Laptop = 16GB GDDR6（不同于Desktop版的24GB GDDR6X）
  • 最佳模型：Qwen3-8B / Llama 3.1-8B / Phi-4 (14B QLoRA)
  • 微调方法：QLoRA（4-bit量化 + LoRA），或LoRA（16-bit）
  • Batch size：4-8（序列长度512时）
  • 序列长度：512-1024
RTX 5090 (32GB GDDR7)：2025年发布的顶级消费级显卡，32GB显存可全参微调13B模型或QLoRA微调约40B模型，是目前消费级最强选择。

MoE模型：大容量低推理成本

MoE（混合专家）模型的总参数量虽大，但推理时只激活一小部分参数，因此实际显存和计算需求远低于总参数量。

模型总参数激活参数推理显存特点
Mixtral 8x7B47B~13B~24GB (FP16)开源MoE先驱
Llama 4 Scout109B17B~32GB (FP16)16专家，10M上下文
Llama 4 Maverick400B17B~32GB (FP16)128专家，1M上下文
DeepSeek V4 Pro1.6T49B云端MIT开源，CSA+HCA
边缘部署推荐：使用 GGUF量化格式 + llama.cpp 或 Ollama，可以在CPU/低显存设备上运行7-14B模型。例如 ollama run qwen2.5:7b 即可一键部署。

动手练习

✏️ 练习1：模型对比测试

目标：在相同任务上对比不同规模模型的效果。

要求：

① 选择3个不同规模的模型（1B, 3B, 7B）

② 在同一个分类任务上测试

③ 对比：准确率、推理速度、内存占用

④ 给出最佳性价比推荐

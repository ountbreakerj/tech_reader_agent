🔧 超参数调优

掌握关键超参数的设置和调优方法

关键超参数概览

类比：超参数就像是做菜的调料配比——盐放多少、油温多高、炒多久。调料配比对了，菜就好吃；配比错了，可能太咸或太生。超参数调优就是找到最佳的"调料配比"。

超参数优先级

文本
# 超参数调优优先级（从高到低）

1. 学习率（Learning Rate）     ← 最重要，影响最大
   推荐范围: 1e-5 到 1e-3

2. 批量大小（Batch Size）      ← 影响稳定性和速度
   推荐范围: 4, 8, 16, 32

3. 训练轮数（Epochs）          ← 防止过拟合
   推荐范围: 3-10

4. Warmup比例                 ← 训练初期的稳定
   推荐范围: 总步数的5%-10%

5. 权重衰减（Weight Decay）    ← 正则化
   推荐范围: 0.01-0.1

6. Dropout率                  ← 防止过拟合
   推荐范围: 0.1-0.3

常见调优陷阱

🚨 常见错误：
  • 学习率太大 → 训练不收敛，损失剧烈震荡
  • 学习率太小 → 训练极慢，可能陷入局部最优
  • Batch size太大 → 显存不足，泛化性能下降
  • 训练轮数太多 → 过拟合，验证集性能下降

学习率调优

LR Range Test

Python 
import torch
import matplotlib.pyplot as plt

def lr_range_test(model, train_loader, optimizer, criterion,
                   lr_start=1e-7, lr_end=10, num_steps=100):
    """学习率范围测试：找到最佳学习率"""
    lrs = []
    losses = []
    best_loss = float('inf')

    # 设置初始学习率
    for pg in optimizer.param_groups:
        pg['lr'] = lr_start

    lr_multiplier = (lr_end / lr_start) ** (1 / num_steps)

    for i, batch in enumerate(train_loader):
        if i >= num_steps:
            break

        # 前向传播
        outputs = model(batch["input_ids"])
        loss = criterion(outputs, batch["labels"])

        # 记录
        lrs.append(optimizer.param_groups[0]['lr'])
        losses.append(loss.item())

        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        # 增大学习率
        for pg in optimizer.param_groups:
            pg['lr'] *= lr_multiplier

    # 绘制学习率-损失曲线
    plt.figure(figsize=(10, 4))
    plt.plot(lrs, losses)
    plt.xlabel('Learning Rate')
    plt.ylabel('Loss')
    plt.xscale('log')
    plt.title('LR Range Test')
    plt.savefig('lr_range_test.png')
    plt.show()

    # 最佳学习率：损失下降最快的地方
    return lrs[losses.index(min(losses))]
解读LR曲线：选择损失下降最快（曲线最陡）的地方对应的学习率，通常是最佳学习率的10倍作为最大值。

批量大小选择

批量大小的影响

批量大小优点缺点适用场景
小（4-8）泛化好，显存占用小训练不稳定，速度慢小数据集，显存有限
中（16-32）平衡平衡大多数情况（推荐）
大（64+）训练稳定，速度快泛化差，显存占用大大数据集，多GPU

accumulation_steps = 4  # 每4步更新一次
actual_batch_size = 8 * accumulation_steps  # 等效batch_size=32

Warmup策略

类比：Warmup就像运动前的热身——刚开始用小步快走，逐渐加速到正常跑步速度。这样可以避免一开始就用太大的学习率导致训练不稳定。
Python
from transformers import get_cosine_schedule_with_warmup

# 余弦衰减 + Warmup（最常用）
num_epochs = 3
num_training_steps = len(train_loader) * num_epochs
num_warmup_steps = int(0.1 * num_training_steps)  # 10% Warmup

scheduler = get_cosine_schedule_with_warmup(
    optimizer,
    num_warmup_steps=num_warmup_steps,
    num_training_steps=num_training_steps
)

# 在训练循环中调用scheduler
for epoch in range(num_epochs):
    for batch in train_loader:
        # ... 训练代码 ...
        scheduler.step()  # 更新学习率

WSD调度策略（2025-2026新趋势）

WSD（Warmup-Stable-Decay）调度：2025-2026年在大规模预训练中越来越流行的三阶段调度策略。DeepSeek V3/V4、MiniCPM等模型均采用了此策略。
文本
# WSD调度策略的三个阶段

阶段1 - Warmup：学习率从0线性增长到峰值
   持续约总步数的5%-10%

阶段2 - Stable：学习率保持恒定
   持续约总步数的80%-90%，占训练主体

阶段3 - Decay：学习率快速衰减到接近0
   持续约总步数的5%-10%，可用余弦或线性衰减

# 优势：Stable阶段可随时停止并进入Decay
# 适合不确定总训练量的场景（如按需扩展训练规模）

学习率与批量大小的关系

线性缩放规则：当你改变批量大小时，学习率也需要相应调整。这是一个常被忽略但非常重要的经验法则。
文本
# 线性缩放规则（Linear Scaling Rule）
# 当batch_size变为k倍时，学习率也应变为k倍

原始设置: batch_size=8,  lr=1e-4
调整后:   batch_size=32, lr=4e-4   # batch_size变4倍，lr也变4倍

# Square Root缩放（更保守，某些场景更稳定）
lr_new = lr_base * sqrt(new_batch_size / base_batch_size)

# 注意：缩放后需要重新调整warmup步数
# 大batch通常需要更长的warmup
实践建议：从较小的batch size和学习率开始，逐步增大。如果增大batch size后训练不稳定，尝试使用square root缩放而非线性缩放。

muP：跨模型规模的超参数迁移

muP（Maximal Update Parametrization）：一种参数化方法，使得在小模型上调优的超参数可以直接迁移到大模型上使用，大幅降低大模型超参数搜索的成本。Cerebras、xAI等团队在训练大规模模型时已采用此方法。
Python
# muP核心思想：调整参数更新的缩放方式
# 使得不同宽度的模型在相同超参数下行为一致

# 使用torch.optim中的实现（PyTorch 2.12+）
# 或使用muP官方库：pip install muP

# 关键区别：
# - 标准参数化：隐藏层宽度变化时，最优学习率也会变化
# - muP：通过调整初始化和学习率缩放，最优学习率保持不变

# 实践流程：
# 1. 在小模型（如125M）上用muP调优超参数
# 2. 将最优超参数直接应用到目标大模型（如7B、70B）
# 3. 仅需微调，无需重新搜索

什么是AI Agent

AI Agent是一个能够自主感知环境、制定计划、执行行动、反思改进的智能系统。

维度聊天机器人AI Agent
交互模式问答式，被动响应主动规划，自主执行
能力范围只能生成文本可调用工具、操作外部系统
记忆仅当前对话短期+长期记忆
任务复杂度单轮问答多步骤复杂任务
自主性低，需要人类引导高，可自主决策

Agent的核心循环：感知(Perceive) → 规划(Plan) → 行动(Act) → 反思(Reflect)，不断循环直到任务完成。

Agent核心能力

能力说明实现方式
规划将复杂任务分解为子步骤CoT、任务分解Prompt
记忆短期（对话历史）+长期（向量数据库）LangGraph Checkpointer / Store、向量存储
工具使用调用外部API、数据库、代码执行器Function Calling
反思评估行动结果，调整策略Self-Reflection、Reflexion

架构模式

模式流程优势适用场景
Workflow (DAG)?预定义流程，按图执行可控、可审计固定业务流程
ReAct?思考→行动→观察→循环灵活、可解释通用Agent
Plan-and-Execute?先规划全部步骤，再逐步执行进度可观测复杂多步任务
Reflexion执行→评估→反思→重试自我纠错需要高准确率的任务
Multi-Agent?多个Agent协作分工专业分工复杂系统

ReAct模式示例

Python 
# ReAct循环伪代码
while not task_done:
    # 思考：分析当前状态，决定下一步
    thought = llm("分析当前情况，决定下一步行动")
    # 行动：执行具体操作
    action = llm("基于思考，选择要执行的动作")
    # 观察：获取行动结果
    observation = execute(action)
    # 更新状态
    state.update(thought, action, observation)

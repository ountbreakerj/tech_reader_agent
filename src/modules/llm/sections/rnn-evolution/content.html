从RNN到LSTM，理解序列建模的前世今生

传统RNN

自然语言天然是序列数据——词语的顺序至关重要。RNN（循环神经网络）是第一个专门为序列建模设计的神经网络。

RNN核心思想

RNN在每个时间步接收当前输入和上一步的隐藏状态，输出新的隐藏状态：

h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b)

RNN架构类型

类型输入/输出示例应用
N vs 1序列输入 → 单一输出文本分类、情感分析
1 vs N单一输入 → 序列输出图像描述生成
N vs N序列输入 → 等长序列输出词性标注、NER
N vs M (Seq2Seq)不等长序列 → 不等长序列机器翻译、文本摘要

PyTorch RNN使用

Python 
import torch
import torch.nn as nn

# PyTorch RNN 使用示例
rnn = nn.RNN(
    input_size=128,     # 输入特征维度
    hidden_size=256,    # 隐藏状态维度
    num_layers=2,       # RNN层数
    batch_first=True,
)

# 输入: [batch_size, seq_length, input_size]
x = torch.randn(32, 50, 128)  # batch=32, 序列长50
output, hidden = rnn(x)

print(f"输出形状: {output.shape}")   # [32, 50, 256]
print(f"隐藏状态: {hidden.shape}")   # [2, 32, 256]

梯度消失与爆炸

RNN最大的问题是梯度消失/爆炸，导致无法学习长距离依赖关系。

问题根源

反向传播时，梯度需要沿时间步连乘：

∂L/∂h_0 = ∏(∂h_t/∂h_{t-1}) · ∂L/∂h_T

  • 如果 |∂h_t/∂h_{t-1}| < 1：连乘后梯度趋近于0（梯度消失）
  • 如果 |∂h_t/∂h_{t-1}| > 1：连乘后梯度趋近于无穷（梯度爆炸）

解决方案

问题解决方案原理
梯度爆炸梯度裁剪（Gradient Clipping）当梯度范数超过阈值时进行缩放
梯度消失LSTM / GRU 门控机制通过门控选择性保留/遗忘信息
梯度消失残差连接（Residual Connection）跳跃连接让梯度直接传播

LSTM详解

LSTM（Long Short-Term Memory）通过三个门控机制解决了梯度消失问题，能够学习长距离依赖。

三个门控

门公式作用
遗忘门 ff = σ(W_f · [h_{t-1}, x_t] + b_f)决定丢弃细胞状态中的哪些信息
输入门 ii = σ(W_i · [h_{t-1}, x_t] + b_i)决定将哪些新信息写入细胞状态
输出门 oo = σ(W_o · [h_{t-1}, x_t] + b_o)决定细胞状态的哪些部分输出

LSTM vs RNN

LSTM引入了细胞状态（Cell State）作为信息的"高速公路"，梯度可以沿细胞状态无阻碍地传播。

Bi-LSTM

双向LSTM同时从左到右和从右到左读取序列，捕捉双向上下文信息：

Python 
import torch
import torch.nn as nn

# LSTM
lstm = nn.LSTM(input_size=128, hidden_size=256,
               num_layers=2, batch_first=True, bidirectional=True)

x = torch.randn(32, 50, 128)
output, (hidden, cell) = lstm(x)

print(f"Bi-LSTM输出: {output.shape}")  # [32, 50, 512] (256*2方向)
print(f"隐藏状态: {hidden.shape}")     # [4, 32, 256] (2层*2方向)

GRU简介

GRU（Gated Recurrent Unit）是LSTM的简化版本，只有两个门，参数量更少。

LSTM vs GRU

特性LSTMGRU
门控数量3个（遗忘/输入/输出）2个（更新/重置）
参数量较多较少（约LSTM的75%）
训练速度较慢较快
效果长序列更好短序列相当
使用建议序列很长、数据充足数据有限、需要快速训练

选型建议：在现代NLP中，LSTM/GRU已被Transformer大幅取代。但在时序预测、边缘设备推理等场景，GRU仍然是不错的选择。

从RNN到Transformer

尽管LSTM/GRU解决了梯度消失，但RNN架构有固有缺陷，最终被Transformer取代。

RNN的固有缺陷

缺陷说明Transformer如何解决
无法并行必须按顺序逐步计算，训练慢自注意力可并行计算所有位置
长距离依赖弱信息经过多步传递会衰减任意两个位置直接交互，路径长度O(1)
信息瓶颈Seq2Seq将整个输入压缩为固定向量注意力机制直接访问所有输入位置

关键转折点：2017年Google发表"Attention Is All You Need"，提出完全基于注意力机制的Transformer架构，摒弃了RNN的循环结构，开启了大模型时代。

实践：LSTM文本分类

用PyTorch实现一个基于Bi-LSTM的情感分析分类器。

Python 
import torch
import torch.nn as nn

class LSTMClassifier(nn.Module):
    """基于LSTM的文本分类器"""
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, num_layers=2,
                           batch_first=True, bidirectional=True, dropout=0.3)
        self.fc = nn.Linear(hidden_dim * 2, num_classes)  # *2 for bidirectional

    def forward(self, x):
        emb = self.embedding(x)            # [B, L, E]
        output, (hidden, _) = self.lstm(emb)  # hidden: [4, B, H]
        # 取最后一层的两个方向拼接
        hidden = torch.cat([hidden[-2], hidden[-1]], dim=1)  # [B, 2*H]
        return self.fc(hidden)              # [B, num_classes]

# 使用示例
model = LSTMClassifier(vocab_size=30000, embed_dim=128,
                       hidden_dim=256, num_classes=2)
x = torch.randint(0, 30000, (32, 50))  # [batch=32, seq_len=50]
logits = model(x)
print(f"分类输出: {logits.shape}")  # [32, 2]

这个LSTM分类器在小数据集上效果不错，但随着数据量增加，BERT微调会显著超越它。

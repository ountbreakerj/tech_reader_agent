LangGraph核心：状态、节点与边

用图结构编排复杂的 LLM 工作流

为什么需要 LangGraph

LangChain 的 Chain 是线性管道（A -> B -> C），数据单向流动。但真实世界的 LLM 应用往往需要循环（审查-修复-再审查）、条件分支（根据结果走不同路径）、人工介入（暂停等待审批）——这些场景用 Chain 很难实现。

LangChain Chain

  • 线性管道 A -> B -> C
  • 数据单向流动
  • 没有原生循环支持
  • 难以实现分支和回退
  • 状态管理靠外部变量

LangGraph

  • 图结构（任意连接）
  • 状态在节点间共享和修改
  • 原生支持循环和条件分支
  • 内置持久化和断点恢复
  • 原生支持 Human-in-the-Loop

类比：LangChain 的 Chain 像是工厂流水线——传送带从头到尾，工位固定顺序。LangGraph 像是地铁线路图——站点（节点）之间可以有任意连接，有环线、有换乘、有分支，你能设计出任意复杂的工作流。

StateGraph 基础：TypedDict State

LangGraph 的一切从 State 开始。State 是一个在所有节点之间共享的数据结构——类似于多人协作的"共享白板"，每个节点都可以读取和修改。

核心概念：State 用 Python 的 TypedDict 定义。每个节点函数接收整个 State，返回一个只包含要更新字段的字典，LangGraph 自动将其合并到 State 中。

Python 
from typing import Annotated, TypedDict
from operator import add

class ChatState(TypedDict):
    # 对话消息列表
    messages: Annotated[list, add]
    # 当前情绪标签
    mood: str
    # 对话轮次
    turn_count: int

Annotated 与 Reducer

写法行为适用场景
field: list节点返回的 list 覆盖原值不需要保留历史的列表
field: Annotated[list, add]节点返回的 list 追加到原值消息历史、日志记录
field: str节点返回的 str 覆盖原值单值字段（覆盖即更新）
field: int节点返回的 int 覆盖原值计数器、状态标志

实用技巧：消息历史字段（messages）几乎总是用 Annotated[list, add]，这样每个节点只需返回新消息，而不是复制整个历史列表。

Node（工作者函数）

Node 是执行实际工作的函数。每个 Node 接收当前 State，执行逻辑，返回一个字典来更新 State 的部分字段。

类比：如果 State 是白板，Node 就是走到白板前的工人。工人读取白板上的内容，做自己的工作，然后把结果写回白板。关键是：每个工人只更新自己负责的字段，不会擦掉别人写的东西。

Python 
from langchain_anthropic import ChatAnthropic
from langchain_core.messages import SystemMessage, AIMessage

llm = ChatAnthropic(model="claude-opus-5")

def chatbot(state: ChatState) -> dict:
    """聊天机器人节点：根据消息历史生成回复"""
    response = llm.invoke(state["messages"])

    # 返回要更新的字段
    return {
        "messages": [AIMessage(content=response.content)],
        "turn_count": state.get("turn_count", 0) + 1
    }

# 情绪分析节点
def analyze_mood(state: ChatState) -> dict:
    """分析用户最新消息的情绪"""
    last_msg = state["messages"][-1].content
    if "开心" in last_msg or "高兴" in last_msg:
        mood = "positive"
    elif "难过" in last_msg or "生气" in last_msg:
        mood = "negative"
    else:
        mood = "neutral"
    return {"mood": mood}

常见错误：Node 函数的返回值必须是字典，只包含要更新的字段。不要返回完整的 State——LangGraph 会自动合并。

Edge（边）与 Conditional Edge（条件边）

Edge 定义了节点之间的连接关系——"做完 A 之后去做 B"。

普通边（add_edge）

Python 
from langgraph.graph import StateGraph, START, END

graph = StateGraph(ChatState)

# 添加节点
graph.add_node("analyze_mood", analyze_mood)
graph.add_node("chatbot", chatbot)

# 普通边：START -> analyze_mood -> chatbot -> END
graph.add_edge(START, "analyze_mood")
graph.add_edge("analyze_mood", "chatbot")
graph.add_edge("chatbot", END)

条件边（add_conditional_edges）

条件边根据当前 State 的值，动态决定下一步走向哪个节点。

Python 
def route_by_mood(state: ChatState) -> str:
    """根据情绪路由到不同的处理节点"""
    mood = state.get("mood", "neutral")
    if mood == "positive":
        return "cheerful_reply"
    elif mood == "negative":
        return "empathetic_reply"
    else:
        return "normal_reply"

# 添加条件边：从 analyze_mood 出发，根据 route_by_mood 的返回值选择目标
graph.add_conditional_edges(
    "analyze_mood",       # 源节点
    route_by_mood,         # 路由函数（接收 state，返回字符串 key）
    {
        "cheerful_reply": "cheerful_reply",    # key -> 目标节点名
        "empathetic_reply": "empathetic_reply",
        "normal_reply": "normal_reply",
    }
)

条件边的三个参数：
1. 源节点（str）：从哪个节点出发
2. 路由函数（callable）：接收 State，返回一个字符串 key
3. 映射字典（dict）：key -> 目标节点名的映射

START 和 END 常量

START 和 END 是 LangGraph 预定义的特殊节点，分别表示图的入口和出口。

常量来源含义用法
STARTfrom langgraph.graph import START图的入口点add_edge(START, "first_node")
ENDfrom langgraph.graph import END图的终止点add_edge("last_node", END)

弃用警告：旧版 API set_entry_point() 和 set_finish_point() 已弃用。请统一使用 add_edge(START, "node") 和 add_edge("node", END)。

graph.compile() 与 graph.invoke()

构建图之后，需要先 compile() 编译，然后才能 invoke() 执行。编译过程会验证图的结构完整性。

1
创建 StateGraph — 传入 State 类型
2
add_node — 注册节点函数
3
add_edge / add_conditional_edges — 定义连接
4
compile — 编译为可执行图
5
invoke / stream — 传入初始 State 运行
Python 
from langchain_core.messages import HumanMessage

# 编译
app = graph.compile()

# 运行
result = app.invoke({
    "messages": [HumanMessage(content="你好，今天我很开心！")],
    "mood": "neutral",
    "turn_count": 0
})

print(result["messages"][-1].content)
print(f"情绪：{result['mood']}")
print(f"对话轮次：{result['turn_count']}")

# 流式运行（查看每个节点的输出）
for event in app.stream(input_state, stream_mode="updates"):
    print(event)

完整示例：构建一个简单的对话机器人

下面是一个完整的对话机器人示例，包含情绪分析和条件路由：

Python 
from typing import Annotated, TypedDict
from operator import add
from langgraph.graph import StateGraph, START, END
from langchain_anthropic import ChatAnthropic
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

# 1. 定义 State
class BotState(TypedDict):
    messages: Annotated[list, add]
    mood: str

# 2. 初始化模型
llm = ChatAnthropic(model="claude-opus-5")

# 3. 定义节点
def detect_mood(state: BotState) -> dict:
    last_msg = state["messages"][-1].content
    if any(w in last_msg for w in ["开心", "高兴", "谢谢"]):
        return {"mood": "happy"}
    elif any(w in last_msg for w in ["难过", "生气", "烦"]):
        return {"mood": "sad"}
    return {"mood": "neutral"}

def happy_reply(state: BotState) -> dict:
    resp = llm.invoke([
        SystemMessage(content="用户心情很好，请用热情积极的语气回复"),
        *state["messages"]
    ])
    return {"messages": [AIMessage(content=resp.content)]}

def sad_reply(state: BotState) -> dict:
    resp = llm.invoke([
        SystemMessage(content="用户心情不好，请用温暖共情的语气回复，给予安慰"),
        *state["messages"]
    ])
    return {"messages": [AIMessage(content=resp.content)]}

def normal_reply(state: BotState) -> dict:
    resp = llm.invoke(state["messages"])
    return {"messages": [AIMessage(content=resp.content)]}

# 4. 定义路由函数
def route(state: BotState) -> str:
    return state["mood"]

# 5. 构建图
graph = StateGraph(BotState)
graph.add_node("detect_mood", detect_mood)
graph.add_node("happy_reply", happy_reply)
graph.add_node("sad_reply", sad_reply)
graph.add_node("normal_reply", normal_reply)

graph.add_edge(START, "detect_mood")
graph.add_conditional_edges("detect_mood", route, {
    "happy": "happy_reply",
    "sad": "sad_reply",
    "neutral": "normal_reply",
})
graph.add_edge("happy_reply", END)
graph.add_edge("sad_reply", END)
graph.add_edge("normal_reply", END)

# 6. 编译并运行
app = graph.compile()
result = app.invoke({
    "messages": [HumanMessage(content="今天考试没考好，心情很糟糕")],
    "mood": "neutral"
})
print(result["messages"][-1].content)

运行流程：用户输入 -> detect_mood（判断情绪）-> 条件路由 -> 对应的回复节点 -> END。整个过程自动完成，无需手动干预。

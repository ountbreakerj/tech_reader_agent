👁️ 模块0：注意力机制详解

Transformer的基石，让模型学会「看哪里」

注意力机制起源

注意力机制最早由Bahdanau等人在2014年提出，用于解决Seq2Seq模型的信息瓶颈问题。

Seq2Seq的瓶颈

传统Seq2Seq将整个输入序列压缩为一个固定长度的向量（上下文向量），然后用这个向量生成输出。

问题：当输入序列很长时，固定向量无法承载所有信息，导致信息丢失。

注意力的突破

注意力机制让解码器在每一步都可以直接查看编码器的所有输出，并根据相关性加权求和：

context = Σ(α_i · h_i)，其中 α_i 是注意力权重

类比：传统Seq2Seq像把一本书压缩成一句话摘要；注意力机制像考试时可以随时翻书查阅。

注意力机制分类

注意力机制分类

类型原理特点应用场景
Soft Attention对所有位置计算加权求和（连续、可微）可端到端训练机器翻译、文本摘要
Hard Attention采样选择少数位置（离散、不可微）需要强化学习训练图像描述生成
Self-Attention序列内部的注意力（Q=K=V来自同一序列）捕捉序列内部关系BERT、GPT的核心
Cross-AttentionQ来自一个序列，K/V来自另一个序列连接两个序列的信息Decoder中的编码器-解码器注意力

Q/K/V机制详解

Q/K/V（查询/键/值）是注意力机制的核心概念。

类比：图书馆检索

概念类比作用
Query (查询)你的搜索关键词表示"我在找什么"
Key (键)书的索引/标签表示"我有什么"
Value (值)书的实际内容表示"我能提供什么"

缩放点积注意力公式

Attention(Q, K, V) = softmax(Q · K^T / √d_k) · V

  • Q · K^T：计算查询和每个键的相似度（点积）
  • / √d_k：缩放因子，防止点积过大导致softmax梯度消失
  • softmax：将相似度转为概率分布（注意力权重）
  • · V：用注意力权重对值加权求和

为什么除以 √d_k？当d_k很大时，点积的值会很大，softmax会趋向于one-hot分布，梯度几乎为零。缩放后梯度更平滑。

Self-Attention计算过程

Self-Attention的完整计算过程：

步骤详解

1
输入嵌入
输入X [seq_len, d_model]，如句子 "我 爱 NLP" 有3个token
2
线性变换
通过W_Q, W_K, W_V三个矩阵将X分别映射为Q, K, V
3
计算注意力分数
scores = Q · K^T，得到 [seq_len, seq_len] 的注意力矩阵
4
缩放
scores = scores / √d_k
5
归一化
对每一行做softmax，得到注意力权重 [0.7, 0.2, 0.1]
6
加权求和
output = weights · V，每个token的输出是所有token的加权组合

核心洞察：Self-Attention让每个token都能"看到"序列中的所有其他token，并根据相关性决定关注程度。这就是为什么Transformer能捕捉长距离依赖。

Scaled Dot-Product Attention 实现

Python 
import torch
import torch.nn as nn
import math

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    缩放点积注意力
    Q, K, V: [batch, heads, seq_len, d_k]
    """
    d_k = Q.size(-1)
    # 计算注意力分数
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    # 可选：应用掩码
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    # softmax归一化
    attn_weights = torch.softmax(scores, dim=-1)
    # 加权求和
    output = torch.matmul(attn_weights, V)
    return output, attn_weights

# 示例
B, H, L, D = 2, 8, 10, 64  # batch, heads, seq_len, d_k
Q = torch.randn(B, H, L, D)
K = torch.randn(B, H, L, D)
V = torch.randn(B, H, L, D)

out, weights = scaled_dot_product_attention(Q, K, V)
print(f"输出: {out.shape}")         # [2, 8, 10, 64]
print(f"注意力权重: {weights.shape}") # [2, 8, 10, 10]

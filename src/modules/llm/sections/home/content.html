📚 学习路径推荐

路径1：NLP→LLM应用开发（6-8周）

  1. NLP基础 → 文本预处理 → 词向量 → 注意力机制 → Transformer
  2. Prompt工程 → 范式演进 → Prompt Engineering → CoT推理
  3. LLM应用 → Function Calling → Agent架构 → RAG系统
  4. 实战项目 → 企业问答系统 → Agent开发

路径2：模型训练与微调（6-8周）

  1. NLP基础 → Transformer原理 → BERT → 预训练模型
  2. 数据处理 → 数据清洗(MinHash去重) → 数据集构建(合成数据)
  3. 训练实战 → 架构理解 → 超参数调优 → 微调(LoRA/PEFT)
  4. 部署上线 → 评估 → 对齐训练 → 部署(vLLM/SGLang)

路径3：Happy-LLM 实战强化（按需穿插）

  1. 原理深化 → Transformer 架构原文 → 从零搭建 LLaMA2
  2. 训练实践 → 预训练数据 → LoRA/QLoRA → 偏好对齐
  3. 应用落地 → 评测 → RAG → Tiny-Agent
  4. 前沿探索 → GRPO/OPD → Search-R1 → 多模态微调

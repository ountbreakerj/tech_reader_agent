📋 重排序算法详解

对初步检索结果进行精排，提升最终质量

为什么需要重排序

类比：初步检索（粗排）就像图书馆的目录检索——快速找到一堆可能相关的书。重排序（精排）就像图书管理员仔细翻阅这些书，挑出最相关的几本——虽然慢一点，但质量高很多。

检索流程

返回Top-50]

Top-5]

Cross-Encoder重排序

Cross-Encoder原理：将查询和文档拼接在一起，直接输入BERT等模型，输出相关性分数。相比双塔模型，Cross-Encoder能更深入地理解查询和文档的交互关系。
Python 
from sentence_transformers import CrossEncoder
import numpy as np

# 加载Cross-Encoder重排序模型
reranker = CrossEncoder("BAAI/bge-reranker-base")

# 示例：对粗排结果重排序
query = "什么是机器学习"
documents = [
    "机器学习是人工智能的一个分支，它使计算机能够从数据中学习",
    "深度学习是机器学习的一个子领域，使用神经网络",
    "今天天气很好，适合出去玩",
    "计算机视觉是AI的重要方向",
]

# 构造查询-文档对
pairs = [(query, doc) for doc in documents]

# 计算相关性分数
scores = reranker.predict(pairs)

# 按分数排序
ranked_indices = np.argsort(scores)[::-1]

print("重排序结果：")
for idx in ranked_indices:
    print(f"分数={scores[idx]:.4f} | {documents[idx][:30]}...")

ColBERT模型

ColBERT的核心定位：ColBERT（Contextualized Late Interaction over BERT）首先是一个高效检索模型（Khattab & Zaharia, 2020），同时也可用于重排序。它在检索阶段就能实现接近Cross-Encoder的精度，同时保持接近双塔模型的速度。

ColBERT工作原理

ColBERT使用延迟交互（Late Interaction）机制：分别独立编码查询和文档，然后在token级别计算相似度。

1
编码阶段：查询和文档分别通过BERT编码器，得到每个token的向量表示（768维）。然后通过一个线性投影层将768维降维到低维空间（如128维），以降低计算成本。
2
MaxSim评分：对查询中的每个token向量，在文档的所有token向量中找到最大余弦相似度，然后将所有查询token的最大相似度求和，得到最终的相关性分数。公式：Score(Q, D) = Σi maxj sim(Eqi, Edj)
3
预计算优化：文档端的token向量可以离线预计算并建立索引，查询时只需编码查询向量，极大加速在线检索。
ColBERT v2改进：ColBERT v2引入了残差压缩（Residual Compression），将token向量存储为聚类中心+残差的形式，大幅降低存储开销（每个向量仅需几个比特），同时保持检索精度。

进阶：Listwise重排序与LLM-as-Reranker

Listwise重排序（RankGPT）

传统Cross-Encoder是pointwise方法——独立对每个查询-文档对打分。而RankGPT采用listwise策略：将查询和一批文档同时提供给LLM，让它直接对整个列表进行重新排序。

1
构造提示：将查询和文档列表（通常10-30个）格式化为一个prompt，要求LLM按相关性从高到低重新排列。
2
滑动窗口：由于LLM上下文窗口有限，RankGPT采用滑动窗口策略——先对底部窗口排序，再逐步向上滑动，最终得到全局排序。
3
优势：LLM具备强大的语义理解能力，能够捕获文档间的相对关系，而非孤立评分。
Python
# Listwise重排序示例（RankGPT思路）
def listwise_rerank(query: str, documents: list[str]) -> list[int]:
    """使用LLM对文档列表进行一次性排序"""
    doc_list = "\n".join(
        [f"[{i+1}] {doc}" for i, doc in enumerate(documents)]
    )
    prompt = f"""给定查询和文档列表，按相关性从高到低重新排列文档编号。

查询：{query}

文档列表：
{doc_list}

请输出排序后的编号列表（用逗号分隔）："""

    response = llm.generate(prompt)
    # 解析返回的编号顺序，如 "3,1,4,2"
    ranked_ids = [int(x.strip()) - 1 for x in response.split(",")]
    return ranked_ids

LLM-as-Reranker

随着大语言模型能力的增强，直接使用LLM作为重排序器正在成为趋势。主要有两种范式：

Pointwise评分

独立评估每个文档的相关性（0-10分），然后按分数排序。简单直接，但忽略了文档间的相对关系。

Listwise排序

将全部文档交给LLM，让它一次性输出排序结果。能捕获文档间关系，但受限于上下文长度。

注意：LLM-as-Reranker的效果通常优于传统Cross-Encoder，但推理成本显著更高（尤其listwise方法需要发送完整文档内容）。在生产环境中需权衡精度与成本，通常只对Top-10~Top-20的候选文档使用LLM重排序。

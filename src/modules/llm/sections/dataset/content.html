数据集划分

类比：数据集划分就像考试——训练集是平时做的练习题，验证集是模拟考试，测试集是真正的高考。练习题要足够多才能学好，模拟考试用来检验学习效果，高考才是最终评判。

划分原则

数据集用途比例关键点
训练集训练模型参数70-80%数据量最大
验证集调整超参数、早停10-15%不参与训练
测试集最终评估10-15%完全隔离
⚠️ LLM训练的划分差异：
  • 预训练阶段：通常不做严格的train/test划分——数据全部用于训练，评估通过下游benchmark完成
  • 指令微调阶段：常用 95/5 或 98/2 的比例（而非80/10/10），因为高质量指令数据稀缺，需要尽量多用于训练
  • 以上80/10/10比例更适用于传统的NLP分类/回归任务

划分代码

Python 
from sklearn.model_selection import train_test_split
import json

# 加载数据
with open("data.jsonl", 'r', encoding='utf-8') as f:
    data = [json.loads(line) for line in f]

# 第一次划分：训练集+临时集（80% + 20%）
train_data, temp_data = train_test_split(
    data,
    test_size=0.2,
    random_state=42,
    shuffle=True
)

# 第二次划分：验证集+测试集（各10%）
val_data, test_data = train_test_split(
    temp_data,
    test_size=0.5,
    random_state=42
)

print(f"训练集: {len(train_data)} 条")
print(f"验证集: {len(val_data)} 条")
print(f"测试集: {len(test_data)} 条")

# 保存划分后的数据
for name, dataset in [("train", train_data), ("val", val_data), ("test", test_data)]:
    with open(f"{name}.jsonl", 'w', encoding='utf-8') as f:
        for item in dataset:
            f.write(json.dumps(item, ensure_ascii=False) + '\n')
⚠️ 避免数据泄漏：划分时要确保训练集和测试集没有重叠，否则会高估模型性能。

数据加载优化

PyTorch DataLoader

Python 
from torch.utils.data import DataLoader, Dataset

class TextDataset(Dataset):
    def __init__(self, texts, labels, tokenizer, max_length=512):
        self.texts = texts
        self.labels = labels
        self.tokenizer = tokenizer
        self.max_length = max_length

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        encoding = self.tokenizer(
            self.texts[idx],
            truncation=True,
            padding="max_length",
            max_length=self.max_length,
            return_tensors="pt"
        )
        return {
            "input_ids": encoding["input_ids"].squeeze(),
            "attention_mask": encoding["attention_mask"].squeeze(),
            "labels": self.labels[idx]
        }

# 创建DataLoader
dataset = TextDataset(texts, labels, tokenizer)
dataloader = DataLoader(
    dataset,
    batch_size=32,
    shuffle=True,
    num_workers=4,       # 多进程加载
    pin_memory=True     # 加速GPU传输
)

优化技巧

技巧说明效果
num_workers > 0多进程并行加载数据加速2-4倍
pin_memory=True数据固定在内存，加速GPU传输加速10-20%
prefetch_factor=2提前加载下一批数据减少等待时间
内存映射（mmap）大文件不完全加载到内存节省内存

数据增强

类比：数据增强就像用不同的方式说同一句话——用同义词替换、改变语序、翻译后再翻译回来——这样能增加数据的多样性，防止模型过拟合。
⚠️ 注意：下面展示的回译、同义词替换等方法主要用于传统NLP分类任务（如文本分类、情感分析）的数据增强。对于LLM预训练和指令微调，更主流的做法是使用合成数据生成（见下一节）。

def synonym_replace(text, synonyms_dict, n=2):
    """同义词替换"""
    words = text.split()
    for _ in range(n):
        idx = random.randint(0, len(words) - 1)
        if words[idx] in synonyms_dict:
            words[idx] = random.choice(synonyms_dict[words[idx]])
    return ' '.join(words)

def random_insert(text, words_pool, n=1):
    """随机插入"""
    words = text.split()
    for _ in range(n):
        idx = random.randint(0, len(words))
        word = random.choice(words_pool)
        words.insert(idx, word)
    return ' '.join(words)

处理不平衡数据

数据不平衡是指不同类别的样本数量差异很大，会导致模型偏向多数类。

解决方法

Python 
from collections import Counter
import random

def oversample_minority(data, labels):
    """过采样少数类"""
    counter = Counter(labels)
    max_count = max(counter.values())

    augmented_data = []
    augmented_labels = []

    for label in counter:
        # 找到这个类别的样本
        class_data = [d for d, l in zip(data, labels) if l == label]

        # 复制样本直到达到最大数量
        while len(class_data) < max_count:
            class_data.append(random.choice(class_data))

        augmented_data.extend(class_data[:max_count])
        augmented_labels.extend([label] * max_count)

    return augmented_data, augmented_labels

def undersample_majority(data, labels):
    """欠采样多数类"""
    counter = Counter(labels)
    min_count = min(counter.values())

    sampled_data = []
    sampled_labels = []

    for label in counter:
        class_data = [d for d, l in zip(data, labels) if l == label]
        sampled = random.sample(class_data, min_count)
        sampled_data.extend(sampled)
        sampled_labels.extend([label] * min_count)

    return sampled_data, sampled_labels
💡 选择建议：
  • 过采样：数据量小时使用，可能增加训练时间
  • 欠采样：数据量大时使用，可能丢失重要信息
  • 权重调整：在损失函数中给少数类更高权重（推荐）

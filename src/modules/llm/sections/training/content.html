⚙️ 训练基础原理

深入理解模型训练的核心机制

前向传播与反向传播

类比：前向传播就像做题——输入题目，经过思考（神经网络计算），给出答案。反向传播就像对答案——计算错误有多大（损失），然后倒推每个步骤应该怎样改进（梯度）。

核心流程

Python 
import torch
import torch.nn as nn

# 前向传播
def forward_pass(model, input_data):
    """前向传播：输入 → 模型 → 输出"""
    output = model(input_data)
    return output

# 计算损失
def compute_loss(output, target):
    """计算预测值和真实值的差距"""
    loss_fn = nn.CrossEntropyLoss()
    loss = loss_fn(output, target)
    return loss

# 反向传播
def backward_pass(loss, model):
    """反向传播：计算梯度"""
    loss.backward()  # 自动计算所有参数的梯度

# 更新参数
def update_params(model, optimizer):
    """根据梯度更新参数"""
    optimizer.step()    # 执行参数更新
    optimizer.zero_grad()  # 清空梯度，为下一轮准备

优化器详解

类比：优化器就像是下山的策略——损失函数是山谷，我们要找到最低点。SGD是随机下山，Adam则像是聪明的登山者，知道该往哪个方向走、走多远。

优化器对比

优化器特点学习率适用场景
SGD简单，收敛慢0.01-0.1研究、简单模型
Adam自适应学习率，收敛快1e-4到1e-3最常用
AdamW权重衰减修正1e-4到1e-3大模型训练（推荐）

学习率设置经验：

  • 预训练：1e-4 到 5e-4
  • 微调：1e-5 到 5e-5
  • QLoRA微调：2e-4 到 3e-4

学习率调度策略对比

策略流程使用场景
Warmup + Cosine Decay先线性升温，再余弦衰减最常用，GPT/LLaMA等均使用
WSD (Warmup-Stable-Decay)先升温，保持稳定学习率，最后快速衰减MiniCPM, Phi-3使用，训练中途可灵活截断
Linear Decay线性降低学习率至零简单任务

WSD调度器详解：WSD（Warmup-Stable-Decay）将训练分为三个阶段——Warmup升温、Stable保持恒定学习率、Decay快速衰减。其最大优势是训练中途可灵活截断：在Stable阶段的任意时间点停止训练，都能获得一个可用的模型（只需补一个短Decay阶段）。MiniCPM和Phi-3的实践证明WSD效果不亚于Cosine Decay。

混合精度训练

混合精度训练使用FP16/BF16和FP32混合计算，显著加速训练并减少显存占用。

Python
# PyTorch 2.x+ 推荐写法（旧版 torch.cuda.amp 已废弃）
from torch.amp import autocast, GradScaler

# 指定设备类型为 'cuda'
scaler = GradScaler("cuda")

for batch in dataloader:
    optimizer.zero_grad()

    # 混合精度前向传播
    with autocast("cuda", dtype=torch.bfloat16):  # 推荐BF16
        outputs = model(batch["input_ids"])
        loss = criterion(outputs, batch["labels"])

    # 混合精度反向传播
    scaler.scale(loss).backward()

    # 梯度裁剪（防止梯度爆炸，LLM训练必备）
    scaler.unscale_(optimizer)
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

    scaler.step(optimizer)
    scaler.update()
精度显存占用训练速度精度损失特点
FP32基准基准无最稳定，显存最大
FP16减半提升1.5-2倍轻微动态范围小，需要loss scaling
BF16减半提升1.5-2倍更小推荐：动态范围与FP32相同，无需loss scaling

BF16 vs FP16 实用区别：

  • BF16（Brain Float 16）：8位指数 + 7位尾数，动态范围与FP32相同，不容易溢出，不需要loss scaling。Ampere及以后的GPU支持（RTX 30系/40系/50系）
  • FP16：5位指数 + 10位尾数，动态范围小，容易出现梯度上溢/下溢，必须配合GradScaler使用
  • 实践建议：如果GPU支持BF16（几乎2020年后的GPU都支持），优先使用BF16，训练更稳定

梯度裁剪

LLM训练中，梯度爆炸是导致训练崩溃的常见原因。梯度裁剪（Gradient Clipping）是稳定训练的必备技术。

Python
# 梯度裁剪：限制梯度范数不超过阈值
# 这是LLM训练的标准操作，几乎所有大模型训练都使用

loss.backward()

# 计算所有参数梯度的全局范数，如果超过max_norm则等比缩放
grad_norm = torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0       # 常用值：0.5~1.0
)

optimizer.step()
optimizer.zero_grad()

# 监控梯度范数（用于调试训练不稳定问题）
print(f"梯度范数: {grad_norm:.4f}")  # 如果持续接近max_norm，说明训练不稳定

梯度裁剪经验：

  • 预训练：通常设 max_norm=1.0
  • 微调：通常设 max_norm=0.5~1.0
  • 如果训练loss突然飙升（loss spike），适当降低max_norm

分布式训练框架

当模型参数量超过单卡显存时，需要使用分布式训练框架将训练任务分配到多张GPU上。

框架开发者核心策略适用场景
DeepSpeed ZeRO微软将优化器状态/梯度/参数分片到多卡单机多卡到大规模集群
FSDP2PyTorch原生全分片数据并行，PyTorch 2.x内置PyTorch生态无缝集成
Megatron-LMNVIDIA张量并行+流水线并行+数据并行超大模型训练（100B+）

选择建议：单机2-4卡用 FSDP2（PyTorch原生，配置简单）；多机大规模训练用 DeepSpeed ZeRO（更灵活）；超大模型用 Megatron-LM（张量并行性能最强）。

从Attention Is All You Need到现代LLM的基石

整体架构

Transformer（2017, Google）彻底取代了RNN/LSTM，成为现代NLP和LLM的统一架构。

核心组件

组件作用位置
Input Embedding将词索引转为稠密向量输入层
Positional Encoding注入位置信息（正弦/余弦编码）输入层
Multi-Head Attention多头自注意力，捕捉token间关系核心
Feed-Forward Network两层全连接网络，增加非线性能力核心
Layer Normalization稳定训练，加速收敛每个子层后
Residual Connection跳跃连接，缓解梯度消失每个子层

位置编码

Transformer没有循环结构，需要额外注入位置信息。正弦位置编码使用不同频率的正弦/余弦函数：

PE(pos, 2i) = sin(pos / 10000^(2i/d_model))

PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

现代位置编码变体

方法原理优势代表模型
正弦编码固定公式，不可训练可外推到更长序列原始Transformer
可学习编码可训练的位置嵌入灵活，效果好BERT, GPT-2
RoPE旋转位置编码，编码相对位置天然支持相对位置，外推性好LLaMA, Qwen
ALiBi线性偏置注意力无需额外参数，外推性强BLOOM

多头注意力

多头注意力是Transformer的核心创新。它让模型同时从多个角度（"头"）关注输入的不同部分。

计算过程

  1. 输入X通过三个线性变换得到 Q（查询）、K（键）、V（值）
  2. 将Q、K、V分成n_heads个头（每个头维度 = d_model / n_heads）
  3. 每个头独立计算缩放点积注意力：Attention(Q,K,V) = softmax(QK^T / √d_k) V
  4. 拼接所有头的输出，通过线性变换得到最终结果

PyTorch实现

Python 
import torch
import torch.nn as nn
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads

        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, L, _ = x.shape
        # 线性变换 + 分头
        Q = self.W_q(x).view(B, L, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(x).view(B, L, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(x).view(B, L, self.n_heads, self.d_k).transpose(1, 2)
        # 缩放点积注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float("-inf"))
        attn = torch.softmax(scores, dim=-1)
        out = torch.matmul(attn, V)
        # 拼接 + 输出投影
        out = out.transpose(1, 2).contiguous().view(B, L, self.d_model)
        return self.W_o(out)

多头的意义：不同的头可以关注不同类型的模式——有的头关注语法关系，有的关注语义相似度，有的关注位置关系。

前馈网络与残差连接

前馈网络（FFN）

每个Transformer层都包含一个两层的前馈网络：

FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

内部维度通常是d_model的4倍（如d_model=768, d_ff=3072）。

残差连接 + Layer Normalization

每个子层（Attention或FFN）都有残差连接和层归一化：

  • Post-LN（原始Transformer）：LayerNorm(x + SubLayer(x))
  • Pre-LN（现代模型常用）：x + SubLayer(LayerNorm(x))

Pre-LN比Post-LN训练更稳定，是现代LLM（GPT、LLaMA等）的标准选择。

Encoder与Decoder块

Encoder块

  1. 多头自注意力（Self-Attention）
  2. 残差连接 + LayerNorm
  3. 前馈网络（FFN）
  4. 残差连接 + LayerNorm

Decoder块

  1. 掩码多头自注意力（Masked Self-Attention，防止看到未来token）
  2. 残差连接 + LayerNorm
  3. 交叉注意力（Cross-Attention，Q来自Decoder，KV来自Encoder）
  4. 残差连接 + LayerNorm
  5. 前馈网络（FFN）
  6. 残差连接 + LayerNorm

因果掩码（Causal Mask）

Decoder-only模型（GPT、LLaMA）使用因果掩码，确保每个位置只能看到之前的位置：

Python 
import torch

# 创建因果掩码（下三角矩阵）
def create_causal_mask(seq_len):
    mask = torch.tril(torch.ones(seq_len, seq_len))
    return mask.unsqueeze(0).unsqueeze(0)

# 4个token的因果掩码
mask = create_causal_mask(4)
print(mask)
# tensor([[[1, 0, 0, 0],
#           [1, 1, 0, 0],
#           [1, 1, 1, 0],
#           [1, 1, 1, 1]]])

实践：实现Transformer Encoder

从零实现一个简化版Transformer Encoder层，包含多头注意力、前馈网络、残差连接和LayerNorm。

PyTorch实现

Python 
import torch
import torch.nn as nn
import math

class TransformerEncoderLayer(nn.Module):
    def __init__(self, d_model=512, n_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model),
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.drop = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        # Self-Attention + Residual + LN (Pre-LN)
        attn_out, _ = self.attn(self.norm1(x), self.norm1(x), self.norm1(x),
                                attn_mask=mask)
        x = x + self.drop(attn_out)
        # FFN + Residual + LN
        ffn_out = self.ffn(self.norm2(x))
        x = x + self.drop(ffn_out)
        return x

# 使用示例
layer = TransformerEncoderLayer()
x = torch.randn(2, 10, 512)  # [batch=2, seq_len=10, d_model=512]
out = layer(x)
print(out.shape)  # torch.Size([2, 10, 512])

与PyTorch内置对比

Python 
import torch.nn as nn

# 使用PyTorch内置的Transformer Encoder
encoder_layer = nn.TransformerEncoderLayer(
    d_model=512, nhead=8, dim_feedforward=2048,
    dropout=0.1, batch_first=True, norm_first=True,  # Pre-LN
)
encoder = nn.TransformerEncoder(encoder_layer, num_layers=6)

x = torch.randn(2, 10, 512)
out = encoder(x)
print(out.shape)  # torch.Size([2, 10, 512])

实际开发中建议使用 nn.TransformerEncoderLayer 等内置模块，它们经过了充分的性能优化。从零实现主要用于学习理解。

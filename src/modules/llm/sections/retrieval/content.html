稀疏检索算法

类比：稀疏检索就像是关键词搜索——你输入"机器学习入门"，系统查找包含这些关键词的文档。优点是精确匹配，缺点是无法理解语义。

TF-IDF

Python 
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

# 文档集
documents = [
    "机器学习是人工智能的一个分支",
    "深度学习使用神经网络进行学习",
    "自然语言处理是AI的重要方向",
]

# 创建TF-IDF向量化器
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(documents)

# 查询
query = "什么是机器学习"
query_vector = vectorizer.transform([query])

# 计算相似度
similarities = cosine_similarity(query_vector, tfidf_matrix)[0]
top_idx = np.argmax(similarities)

print(f"最相关文档: {documents[top_idx]}")
print(f"相似度: {similarities[top_idx]:.4f}")

BM25

Python
# 使用rank_bm25库
# pip install rank_bm25

from rank_bm25 import BM25Okapi
import jieba

# 分词
tokenized_docs = [list(jieba.cut(doc)) for doc in documents]

# 创建BM25索引
bm25 = BM25Okapi(tokenized_docs)

# 查询
query = "什么是机器学习"
tokenized_query = list(jieba.cut(query))

# 搜索
scores = bm25.get_scores(tokenized_query)
top_idx = np.argmax(scores)

print(f"最相关文档: {documents[top_idx]}")
print(f"BM25分数: {scores[top_idx]:.4f}")

BM25评分公式

BM25是TF-IDF的改进版本，引入了文档长度归一化和词频饱和度控制：

BM25公式：
score(D, Q) = Σ IDF(qi) * [f(qi, D) * (k1 + 1)] / [f(qi, D) + k1 * (1 - b + b * |D| / avgdl)]

其中：f(qi, D) = 词qi在文档D中的词频，|D| = 文档长度，avgdl = 平均文档长度
k1 = 1.2（词频饱和参数），b = 0.75（文档长度归一化参数）
IDF(qi) = log((N - n(qi) + 0.5) / (n(qi) + 0.5) + 1)，N为文档总数，n(qi)为包含qi的文档数

稠密检索（Dense Retrieval）

类比：稠密检索就像是语义搜索——即使查询和文档没有相同的词，只要意思相近，也能找到。比如查"猫"能找到"小花喵喵叫"。
Python
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

# 加载中文Embedding模型
model = SentenceTransformer("BAAI/bge-base-zh-v1.5")

# 生成文档向量
doc_embeddings = model.encode(documents)

# 生成查询向量
query = "什么是机器学习"
query_embedding = model.encode([query])

# 计算相似度
similarities = cosine_similarity(query_embedding, doc_embeddings)[0]
top_idx = np.argmax(similarities)

print(f"最相关文档: {documents[top_idx]}")
print(f"相似度: {similarities[top_idx]:.4f}")

算法类型速度精度内存适用场景
HNSW图索引快高高频繁查询、数据量<1000万（推荐）

注意区分算法和库：FAISS（Meta）、Milvus、Annoy 是库，它们内部实现了上述多种算法。例如 FAISS 同时支持 IVF、HNSW、PQ 等多种索引类型。选择时应根据算法特性决定，而非仅看库名称。
算法选择：
  • 数据量<1000万：HNSW（精度最高，推荐首选）
  • 数据量1000万-1亿：IVF + HNSW
  • 数据量>1亿、内存受限：IVF-PQ（量化压缩）
  • 数据量>10亿、无法装入内存：DISKANN（磁盘索引）

学习型稀疏检索（Learned Sparse Retrieval）

传统BM25使用固定的词频统计，而学习型稀疏检索通过神经网络学习词项的重要性权重，并能自动扩展相关词汇，在保持可解释性的同时超越BM25的效果。

SPLADE

SPLADE（Sparse Lexical and Expansion）是代表性模型，通过掩码语言模型（MLM）的权重来学习词项重要性，并自动扩展相关词汇。例如查询"机器学习"时，SPLADE可能自动扩展出"深度学习"、"神经网络"等相关词项。

实践推荐：BGE-M3模型原生支持sparse retrieval，一个模型同时产出dense、sparse和ColBERT三种表征，是目前多语言场景下的最佳选择。SPLADE在英文benchmark上表现优异，但中文支持较弱。

ColBERT：延迟交互检索

ColBERT（Contextualized Late Interaction over BERT）是一种"延迟交互"模型，既保留了token级别的细粒度语义信息，又支持高效检索，是介于单向量稠密检索和交叉编码器之间的重要范式。

核心原理：MaxSim 评分

与传统单向量模型将整个文档压缩为一个向量不同，ColBERT为文档中的每个token生成独立的上下文向量。检索时使用MaxSim评分：

MaxSim公式：
Score(Q, D) = Σ_i max_j cosine_similarity(E_qi, E_dj)

对查询中的每个token，找到文档中与其最相似的token（取最大余弦相似度），然后将所有查询token的最大相似度求和。这样既保留了token级别的语义细节，又能高效计算。
版本特点存储方式
ColBERT v1原始延迟交互模型全精度向量，存储开销大
ColBERT v2残差压缩，精度损失极小残差压缩，存储效率高
ColBERT的双重角色：ColBERT既可作为第一阶段检索器（直接在token向量上做ANN检索），也可作为重排序器（对初筛结果精细打分）。BGE-M3模型的ColBERT表征可用于这两个阶段，实现端到端的高质量检索。

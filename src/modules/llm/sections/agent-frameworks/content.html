LangChain Agent入门

Python 
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """搜索互联网获取信息"""
    return f"搜索结果: {query}的相关信息..."

@tool
def calculate(expression: str) -> str:
    """计算数学表达式"""
    return str(eval(expression))

# LangChain v1 推荐入口
agent = create_agent(
    model=ChatOpenAI(model="gpt-5.5", temperature=0),
    tools=[search, calculate],
    system_prompt="你是一个有用的助手，可以使用工具完成任务。",
)

result = agent.invoke({
    "messages": [{"role": "user", "content": "北京的人口乘以2是多少?"}]
})
print(result["messages"][-1].content)

LangGraph构建Agent

LangGraph使用有向图定义Agent的工作流，支持条件分支、循环、并行等复杂控制流。

LangGraph的优势：状态持久化、人类介入(HITL)、检查点恢复，适合生产级Agent系统。

CrewAI示例

Python 
from crewai import Agent, Task, Crew

# 定义Agent角色
researcher = Agent(
    role="研究员",
    goal="搜索并分析最新技术资料",
    backstory="你是一位资深AI研究员",
    llm="gpt-5.5",
)
writer = Agent(
    role="技术作家",
    goal="将研究成果写成通俗易懂的文章",
    backstory="你是一位技术博客作者",
    llm="gpt-5.5",
)

# 定义任务
research_task = Task(description="研究RAG最新进展", agent=researcher)
write_task = Task(description="撰写技术博客", agent=writer)

# 执行
crew = Crew(agents=[researcher, writer],
            tasks=[research_task, write_task])
result = crew.kickoff()

评估与调试

问题表现解决方案
无限循环Agent反复执行相同动作设置最大步数限制、循环检测
工具选择错误调用了不合适的工具改进工具描述、添加示例
幻觉编造不存在的信息RAG增强、事实校验
效率低步骤过多、耗时长优化Prompt、缓存中间结果

# LangChain v1 Agent 调试：限制图步数并观察每次状态更新
config = {"recursion_limit": 10}
inputs = {"messages": [{"role": "user", "content": "复杂任务"}]}

for update in agent.stream(
    inputs,
    config=config,
    stream_mode="updates",
):
    print(update)  # 节点名、工具结果与新增消息

# 完整结果的 messages 保留工具调用与 ToolMessage，可用于轨迹分析
result = agent.invoke(inputs, config=config)
for message in result["messages"]:
    print(message.type, message.content)

Agent开发的最佳实践：先用简单任务验证单步能力，再逐步增加复杂度。始终设置超时和最大步数限制。

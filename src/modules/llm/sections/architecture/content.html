从RNN到Transformer的演进

类比：RNN就像是一个只能一个字一个字读文章的人——读到后面就忘了前面。Transformer则像一个能同时看到整篇文章所有内容的超人——能捕捉全文的所有关联。

RNN的问题

❌ RNN的局限

  • 梯度消失/爆炸，难以学习长距离依赖
  • 串行计算，无法并行，训练慢
  • 信息随时间衰减

✅ Transformer的优势

  • Self-Attention，直接建模任意距离的依赖
  • 高度并行化，训练效率高
  • 全局视野，捕捉全文信息

Transformer架构详解

Self-Attention机制

类比：Self-Attention就像是阅读理解——当你看到"它"这个字时，你需要回头看上下文，找出"它"指的是什么。Attention机制让模型能自动学习每个词应该关注哪些其他词。

Q、K、V的计算

Python 
import torch
import torch.nn as nn
import math

class SelfAttention(nn.Module):
    def __init__(self, embed_size, heads):
        super().__init__()
        self.embed_size = embed_size
        self.heads = heads
        self.head_dim = embed_size // heads

        # Q、K、V按 head_dim 投影（forward 中先分头）
        self.values = nn.Linear(self.head_dim, self.head_dim, bias=False)
        self.keys = nn.Linear(self.head_dim, self.head_dim, bias=False)
        self.queries = nn.Linear(self.head_dim, self.head_dim, bias=False)
        self.fc_out = nn.Linear(heads * self.head_dim, embed_size)

    def forward(self, values, keys, query, mask):
        N = query.shape[0]
        value_len, key_len, query_len = values.shape[1], keys.shape[1], query.shape[1]

        # 先分割成多个头，再对每个头做 head_dim → head_dim 投影
        queries = self.queries(query.reshape(N, query_len, self.heads, self.head_dim))
        keys = self.keys(keys.reshape(N, key_len, self.heads, self.head_dim))
        values = self.values(values.reshape(N, value_len, self.heads, self.head_dim))

        # 计算注意力分数
        energy = torch.einsum("nqhd,nkhd->nhqk", [queries, keys]) / math.sqrt(self.head_dim)

        # 应用mask（可选）
        if mask is not None:
            energy = energy.masked_fill(mask == 0, float("-1e20"))

        # Softmax归一化
        attention = torch.softmax(energy, dim=3)

        # 加权求和：l 是与 attention 的 key 维对应的 value 序列维
        out = torch.einsum("nhql,nlhd->nqhd", [attention, values]).reshape(N, query_len, self.heads * self.head_dim)

        return self.fc_out(out)

位置编码（Positional Encoding）

Python 
class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))

        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        pe = pe.unsqueeze(0)
        self.register_buffer('pe', pe)

    def forward(self, x):
        return x + self.pe[:, :x.size(1)]

现代注意力机制

原始Transformer的Self-Attention计算复杂度为O(n^2)，对长序列效率极低。2022年以来，一系列注意力机制创新大幅提升了训练和推理效率。

机制提出者核心思想使用者
Flash AttentionTri Dao (2022-2024)IO感知的精确注意力，减少HBM读写，显存从O(n^2)降至O(n)几乎所有现代LLM
RoPERoFormer (2021，arXiv:2104.09864)旋转位置编码，直接编码相对位置，天然支持长度外推Llama系列, Qwen, Mistral, DeepSeek
GQAAinslie et al. (2023)多个Query头共享KV头，减少KV Cache显存Llama 2/3/4, Mistral, Qwen
MLADeepSeek V2 (2024)将KV压缩到低维潜空间，大幅减少KV CacheDeepSeek V2/V3/V4
CSA / HCADeepSeek V4 (2026)压缩稀疏注意力/重度压缩注意力，动态选择关键tokenDeepSeek V4
Sliding WindowMistral (2023)只关注局部窗口内的token，通过层数堆叠获得全局视野Mistral, Mixtral

Flash Attention是最重要的效率创新：几乎所有2023年后的LLM训练和推理框架都内置了Flash Attention。它不改变注意力的数学结果，只是通过优化GPU内存访问模式（tiling + recomputation），将训练速度提升2-4倍，同时精确计算注意力（非近似）。

GQA vs MHA vs MLA

传统 MHA

  • 每个头独立的Q/K/V
  • KV Cache随头数线性增长
  • 长序列推理显存瓶颈

GQA / MLA

  • GQA：多Query头共享KV头（Llama 3）
  • MLA：KV压缩到潜空间（DeepSeek）
  • KV Cache大幅减少，推理更高效

替代架构与混合架构

Transformer并非唯一选择。近年来出现了多种替代架构，在特定场景下展现优势。

架构代表模型核心思想优势现状
State Space Models (SSM)Mamba 1 (2023), Mamba 2 (2024)用状态空间方程替代注意力，O(n)复杂度长序列高效，推理快研究活跃，逐步落地
RWKVRWKV-5/6 (2024-2025)RNN架构但能像Transformer一样并行训练推理O(1)内存，训练可并行开源社区持续迭代
MoEMixtral, DeepSeek V3/V4, Llama 4总参数量大，但每次推理只激活部分专家大容量+低推理成本2025-2026成为主流
HybridJamba (Mamba+Transformer)结合SSM和Transformer的优势兼顾效率和性能初步商用

MoE（混合专家模型）详解：MoE是当前最重要的架构趋势。例如 Llama 4 Scout 总参数109B但每次推理只激活17B参数（16个专家），DeepSeek V4 总参数1.6T但只激活49B。这意味着模型拥有超大知识容量，同时推理成本只与小模型相当。

流式输出与部署

实现流畅的流式体验和生产环境部署

流式输出模式

LangGraph 支持多种流式输出模式，通过 stream_mode 参数选择。不同的模式适用于不同的前端需求。

模式说明输出格式适用场景
"values"每步返回完整 Statedict（完整 State）调试、查看每步完整输出
"updates"每步只返回变化部分{node_name: {field: value}}增量更新 UI、日志记录
"messages"LLM 逐 token 流式输出(AIMessageChunk, metadata)聊天界面实时显示回复
"custom"自定义流式事件自定义格式需要精细控制输出格式

"updates" 模式 — 增量更新

Python 
# "updates" 模式：每步只返回变化部分
for event in app.stream(input_state, config=config, stream_mode="updates"):
    # event = {"node_name": {"field": "new_value"}}
    for node_name, updates in event.items():
        print(f"[{node_name}] {updates}")

# 示例输出：
# [detect_mood] {"mood": "happy"}
# [happy_reply] {"messages": [AIMessage(...)]}

"messages" 模式 — 逐 Token 流式

Python 
# "messages" 模式：LLM 逐 token 流式输出
for msg, metadata in app.stream(
    input_state, config=config, stream_mode="messages"
):
    # msg 是 AIMessageChunk 对象
    # metadata 包含节点名称等元信息
    if msg.content:
        print(msg.content, end="", flush=True)

# 示例输出（逐字显示）：
# 你 -> 好 -> ！ -> 今 -> 天 -> 天 -> 气 -> ...

组合多种模式

Python 
# 同时使用多种流式模式
for event in app.stream(
    input_state, config=config,
    stream_mode=["updates", "messages"]
):
    mode, data = event
    if mode == "messages":
        # 实时显示 LLM 生成的 token
        if data.content:
            print(data.content, end="")
    elif mode == "updates":
        # 显示节点级别的状态更新
        print(f"\n[节点更新] {data}")

astream_events 详细用法

astream_events 提供了最细粒度的事件流，可以捕获管道中每个组件的执行细节。

类比：如果 stream 是看"每道菜端上桌"，那 astream_events 就是看"厨师的每个操作步骤"——洗菜、切菜、下锅、翻炒、装盘，每一步都看得到。

Python 
async def stream_events_demo():
    async for event in app.astream_events(
        input_state,
        config=config,
        version="v2"
    ):
        kind = event["event"]
        name = event.get("name", "")

        if kind == "on_chat_model_stream":
            # LLM 逐 token 输出
            content = event["data"]["chunk"].content
            if content:
                print(content, end="", flush=True)

        elif kind == "on_tool_start":
            # 工具开始执行
            print(f"\n[调用工具] {name}")

        elif kind == "on_tool_end":
            # 工具执行完成
            result = event["data"]["output"]
            print(f"[工具结果] {result}")

        elif kind == "on_chain_start":
            print(f"[开始] {name}")

        elif kind == "on_chain_end":
            print(f"[完成] {name}")

事件类型：astream_events 的事件类型包括：on_chat_model_stream（LLM token）、on_tool_start/on_tool_end（工具调用）、on_chain_start/on_chain_end（链执行）、on_retriever_start/on_retriever_end（检索）等。通过 include_names 参数可以过滤只关注的组件。

Token-by-Token 流式显示

在聊天应用中，用户期望看到 LLM 逐字生成回复的流畅体验。以下是实现方式：

Python 
# 方式一：使用 "messages" stream_mode（推荐）
for msg, metadata in app.stream(
    {"messages": [HumanMessage(content="你好")]},
    config=config,
    stream_mode="messages"
):
    if isinstance(msg, AIMessageChunk) and msg.content:
        print(msg.content, end="", flush=True)

# 方式二：使用 create_agent 的流式输出
agent = create_agent(model=llm, tools=tools)
for msg, metadata in agent.stream(
    {"messages": [HumanMessage(content="查一下北京天气")]},
    stream_mode="messages"
):
    # 过滤只显示最终回复（跳过工具调用的中间消息）
    if metadata.get("langgraph_node") == "agent":
        if isinstance(msg, AIMessageChunk) and msg.content:
            print(msg.content, end="", flush=True)

前端集成：在 Web 应用中，通常使用 Server-Sent Events (SSE) 将 token 流式推送到前端。LangGraph 的 stream 方法返回的迭代器天然适合转换为 SSE 格式。

FastAPI 集成部署

如果不想使用 LangGraph Platform，也可以用 FastAPI 自行搭建 API 服务。

Python 
# server.py — FastAPI 集成 LangGraph
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from pydantic import BaseModel
from langchain_core.messages import HumanMessage
import json

app = FastAPI(title="LangGraph API")

# 假设 graph 已在 agent.py 中定义并编译
from agent import graph  # 你的 LangGraph 应用

class ChatRequest(BaseModel):
    message: str
    thread_id: str = "default"

# 同步调用端点
@app.post("/chat")
async def chat(req: ChatRequest):
    config = {"configurable": {"thread_id": req.thread_id}}
    result = await graph.ainvoke(
        {"messages": [HumanMessage(content=req.message)]},
        config=config
    )
    return {"reply": result["messages"][-1].content}

# 流式调用端点（SSE）
@app.post("/chat/stream")
async def chat_stream(req: ChatRequest):
    config = {"configurable": {"thread_id": req.thread_id}}
    input_state = {"messages": [HumanMessage(content=req.message)]}

    async def event_generator():
        async for msg, metadata in graph.astream(
            input_state, config=config, stream_mode="messages"
        ):
            if hasattr(msg, "content") and msg.content:
                data = json.dumps({"token": msg.content})
                yield f"data: {data}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream"
    )

运行方式：uvicorn server:app --host 0.0.0.0 --port 8000。前端使用 EventSource 或 fetch API 连接 /chat/stream 端点即可接收 token 流。

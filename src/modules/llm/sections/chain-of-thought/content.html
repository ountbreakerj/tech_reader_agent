🧩 模块0：Chain-of-Thought与高级提示技术

释放大模型的推理能力

Chain-of-Thought (CoT)

CoT（思维链）让模型在回答前先展示推理步骤，显著提升复杂推理任务的效果。

两种CoT方式

Zero-shot CoT

  • 在Prompt末尾加"Let's think step by step"
  • 无需示例
  • 简单但有效
  • 适合数学/逻辑推理

Few-shot CoT

  • 提供带推理链的示例
  • 效果更好
  • 需要精心设计示例
  • 适合复杂推理

效果对比

方法GSM8K数学准确率说明
直接回答~18%不使用CoT
Zero-shot CoT~42%加"Let's think step by step"
Few-shot CoT~57%提供推理示例

🔑 CoT的原理：引导模型将复杂问题分解为简单步骤，每步推理都可以被验证，从而提升最终答案的准确性。

In-Context Learning (ICL)

ICL是大模型的核心能力之一——通过少量示例（不更新参数）学习新任务。

示例选择策略

策略原理效果
随机选择从训练集中随机抽取基线
相似度选择选择与输入最相似的示例好（推荐）
多样性选择选择覆盖不同模式的示例好
混合策略相似+多样性的组合最好

示例顺序的影响

研究表明，示例的排列顺序会影响输出质量。将最相关的示例放在最后（靠近输入）通常效果更好。

指令微调（Instruction Tuning）

指令微调让模型学会"听从指令"，是从GPT-3到ChatGPT的关键技术突破。

模型训练方式关键特点
GPT-3纯预训练能力强但不听指令
InstructGPT预训练 + RLHF学会听从人类指令
ChatGPT预训练 + RLHF + 对话数据自然对话交互
LLaMA-Chat预训练 + SFT + DPO开源指令模型

指令数据格式

Python 
# Alpaca格式
{"instruction": "将以下文本翻译成英文",
 "input": "自然语言处理是AI的分支",
 "output": "Natural language processing is a branch of AI"}

# ShareGPT格式（多轮对话）
{"conversations": [
  {"from": "human", "value": "什么是NLP?"},
  {"from": "gpt", "value": "NLP是自然语言处理的缩写..."}
]}

进阶推理策略

策略原理优势成本
Self-Consistency多次采样取多数投票提升准确性高（多次推理）
Tree-of-Thought树状搜索多条推理路径适合探索性问题很高
ReAct?推理(Reason)+行动(Act)交替可调用工具中
Reflexion生成→评估→反思→改进自我纠错高

💡 实际应用中，Zero-shot CoT + Self-Consistency 是性价比最高的推理增强方案。
